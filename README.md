# Welcome to Critter Clues Kids 👋

This is a fun mobile app meant to educate kids and adults about animals. It is available on the App Store and Google Play! Dive into daily challenges to test your animal knowledge in an interactive way! Whether you're a casual player or an animal enthusiast. Critter Clues Kids offers an entertaining experience for all ages. 

## Overview

Critter Clues Kids is a mobile app designed to entertain and educate users of all ages about animals through interactive gameplay. The app combines intuitive design with captivating content, making it perfect for player who love puzzles, daily games, and learning. Availabel on iOS and Android, Critter Clues Kids makes learning about the animal kingdom easier than ever. 

## Features
   - Engaging Gameplay: Use animal comparison logic (color coded) to find hidden animals, learning along the way
   - Real Definitions: Uses Wikipedia's open API to pull images of animals
   - Cross-Platform: Available on both iOs and Android devices
   - Family-Friendly: Suitable for players of all ages
   - Intuitive Design: Uses familiar interface designs to deliver easy to learn gameplay

## Development Commands

1. Install dependencies
   npm install

2. Expo build
   npm start

3. Build and run developmental build
   eas build --platform ios --profile development    or    eas build --profile development --platform android --clear-cache
   npx expo start

4. Make and Deploy Production Build
   eas build --platform ios --profile production    or    eas build --platform android --profile production
   eas submit --platform ios                        or    eas submit --platform android --latest
